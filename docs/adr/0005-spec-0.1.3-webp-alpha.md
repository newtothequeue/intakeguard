# ADR 0005: Spec 0.1.3. Lossy WebP with alpha → PNG

**Status:** Accepted. Owner decision, 2026-11-21.

## Context
Spec 0.1.2 re-encodes lossy WebP as JPEG q90. The independent review found that a lossy WebP with an
alpha channel (logos, stickers) comes back as JPEG with its transparent areas silently flattened to white:
no warning and no reason code.

## Decision
Lossy WebP **with** an alpha channel (`ALPH` chunk in a VP8X container) → **lossless PNG** (RGBA).
Lossy WebP without alpha → JPEG q90, unchanged. Transparency is never silently flattened.

Options considered: flatten to white with a warning (loses data), or keep lossy WebP (needs a new lossy
encoder dependency). Both were rejected.

## Fixture
`benign-webp-lossy-alpha-to-png`: 16×8 lossy WebP with alpha → output `image/png`, `has-alpha`, dimensions
16×8. The PR #2 engine produces JPEG, so this fixture fails until the builder implements 0.1.3.
