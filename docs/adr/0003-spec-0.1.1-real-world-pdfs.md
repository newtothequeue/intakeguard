# ADR 0003: Spec 0.1.1, driven by real-world false positives

**Status:** Accepted. Approved by the project owner on 2026-11-21.

## Context
An independent review of the ADR 0002 native slice ran 142 real files (14 encoder-made images;
PDFs from LibreOffice, matplotlib, ReportLab, qpdf, pikepdf, Pillow; 120 pdfTeX/system PDFs).
Every image passed and 119 of 120 system PDFs passed. Six genuine false positives came from
three causes, all from producers RAG pipelines see every day:

| Producer | Engine said | Root cause | Whose fault |
|---|---|---|---|
| LibreOffice (and qpdf rewrites of it) | PDF_ACTIVE_CONTENT | `/OpenAction [page /XYZ null null 0]` is a destination, not an action | **Spec**: rejected every `/OpenAction` |
| pikepdf / qpdf blank pages | STRUCTURE_MALFORMED | `/Length 0` Flate streams | Spec silent; engine strict |
| Pillow `Image.save(..., "PDF")` | STRUCTURE_MALFORMED | Free-list head has generation 65536 | Spec silent; engine strict |

The one remaining rejection (a TeX-converted logo) is also flagged by qpdf. It is a correct reject.

## Decisions
1. **Active content is defined by action type, using an inert allowlist** (`format-guarantees.md#pdf`).
   Destinations are never actions. Any action with a `/JS` key is active. Unknown types are active,
   so the rule stays fail-closed. `/Next` chains are followed transitively.
2. **Two narrow tolerances**: empty Flate streams, and generation 65536 on object 0 only.
3. **New reason code `ENGINE_CANCELLED`** (severity error) for caller cancellation.
4. **Report 0.2** (additive): `policyDecision` (accept/transform/reject/error) and `original.complete`.
5. **Dependency approved:** `miniz_oxide 0.8` in `core/`.

## Guard fixtures (so the relaxation can't become a bypass)
Benign guards that must be accepted: OpenAction destination, OpenAction `/GoTo`, an empty Flate
stream, and Pillow-style generation 65536. Adversarial guards that must be rejected: GoTo with a
`/Next` JavaScript chain, a Rendition action carrying `/JS`, an action with no `/S`, page `/AA`
JavaScript, `/Launch`, generation 65536 on a non-zero object, and a damaged last revision (the
bypass the builder found).

## Consequences
The engine needs updates so these fixtures pass (builder's work, not the reviewer's). From now on,
the real-world false-positive sweep becomes a standing check (`tools/differential/`, to be added).
